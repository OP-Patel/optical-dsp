# Arty A7 XADC interface record

This file is the configuration and measurement record for Milestone 06. Fill
the measurement fields from the implemented design and physical tests; do not
replace missing values with estimates.

## Fixed board mapping

| Item | Selection |
|---|---|
| Board input | ChipKit A0, single-ended 0-3.3 V board-scaled input |
| XADC auxiliary channel | VAUX4 |
| Positive FPGA package pin | C6, top-level `vaux4_p` |
| Negative FPGA package pin | C5, top-level `vaux4_n` |
| DRP result address | `7'h14` |
| Result extraction | `DO[15:4]` |

Physical A0 is a single input referenced to board ground. The two VAUX4 FPGA
ports are the internal differential connection after the Arty scaling network;
they are not two external wires the user must drive independently.

## Nominal conversion equation

For the Arty A0 0-3.3 V scaled path:

```text
expected_code = round((applied_voltage / 3.3 V) * 4095)
estimated_voltage = measured_code * 3.3 V / 4095
```

This equation is nominal. The measured table below is the acceptance evidence.

## Acceptance notes

- [x] Codes increase monotonically between the two board-derived endpoints.
- [x] Grounded input offset and spread are recorded.
- [x] No `xadc_fault` occurred during either measurement window after BTN0 reset.
- [ ] The measured rate is consistent with the documented configuration.
- [x] Only board ground and the nominal board 3V3 rail were applied to A0.
- [x] The BPW34 was not used to hide an electrical acquisition issue.

The endpoint test is a functional range check, not a precision calibration,
because the board 3V3 rail was not independently measured. The observed
ground-corrected span is `(4070.5381 - 13.2988) / 4095 = 99.08%` of ideal full
scale.
